# 华为运动健康 17.0.7.310 布局定位记录

## 版本与边界

目标仅为 `com.huawei.health` 17.0.7.310（versionCode `1700007310`）。依据来自目标 APK 的 JADX 产物与 MuMu12 `emulator-5554` 页面层级。服务端新下发且无法识别的内容保持显示。

`HealthAboutActivity` 不安装任何 Hook；仅“我的”列表中的 `IDS_settings_about` 入口可按配置过滤。

## 关键映射

健康功能卡使用当前版本配置文件中的稳定 ID：`SPORTS_CARD_KEY_NEW`、`HEARTRATE_CARD_KAY_NEW`、`SLEEP_CARD_KEY_NEW`、`WEIGHT_CARD_KEY_NEW`、`STRESS_CARD_KEY_NEW`、`BLOODOXYGEN_CARD_KEY_NEW`、`BLOODSUGAR_CARD_KEY_NEW`、`BLOODPRESSURE_CARD_KEY_NEW`、`TEMPERATURE_CARD_KEY_NEW`、`PHYSIOLOGICAL_CYCLE_CARD_KEY_NEW`。

“我的”行项目优先使用目标字符串资源名，不使用显示位置。17.0.7.310 的运行时资源表会把部分资源名压缩为数字，因此同时保留该版本核验后的 `R.string` ID 映射；未知 ID 仍保留显示。

设备页同时覆盖无设备与已有设备状态：`device_card_normal`、`device_card_list_more_add`、`card_device_list`、`device_function_card`、`watchface_card`、推荐/营销/商城一级容器；顶部菜单兼容 `hwappbarpattern_layout_ok_icon` 等当前版本资源名。

运动页的 Banner、快捷入口和课程区块可能在首次生命周期回调后异步装载。模块只在 `SportEntranceFragment` 根视图上注册弱引用、幂等的布局回调，按已核验容器重新应用隐藏状态，不影响其他课程页面。

## 回归要求

- 总开关关闭时四页及底栏保持原样。
- 各解析路径至少单独验证一项，再验证每页“全部精简”。
- 底栏逐项隐藏后剩余项等宽重排；五项全隐藏时仍显示健康。
- 重复进入、返回、滚动、横竖屏和进程重启后无复用污染、空白、崩溃或 ANR。
- 抽查运动记录、添加设备、登录、同步与权限流程未被修改。
