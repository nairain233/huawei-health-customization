# 华为运动健康 17.0.8.320 适配与首页更多入口

## 问题及实际证据

- 输入为 `调试/华为运动健康_17.0.8.320.apk`，Manifest 包名 `com.huawei.health`，versionName `17.0.8.320`，versionCode `1700008320`。
- APK SHA-256：`c4a6254ead66e405e78b9fa3b182423bcff74c5c37a21c6b4103de5db6a163ef`。
- `HookCoordinator` 将仅支持 17.0.8.300 的设置行版本判断用于整个运行时初始化；新版因此在配置入口、布局扫描及其他业务 Hook 安装前全部返回。`HostSettingsFeature` 还将更多入口放在同一个设置行版本判断之后。
- 新版 `HomeFragment.bk()` 读取 `am:CustomTitleBar` 并调用 `setRightButtonOnClickListener(OnClickListener)`；setter 读取 `t:LinearLayout` 并设置原生点击监听。对应资源仍为 `health_tab_titlebar`、`hwappbarpattern_layout_ok_icon`、`hwappbarpattern_ok_icon`。
- 两份旧原包对应的方法/字段分别为 17.0.7.320 的 `bb/ak/p` 和 17.0.8.300 的 `bi/al/q`；这些混淆名称不进入生产匹配条件。
- 新版设置行仍位于 `hw_show_settings_app`，`hw_goal_layout` 直属 `app_setting_activity_layout`。表盘原生设计师、缓存和签名链分别使用 `f2/t0/l2`，已核验完整方法及回调字段契约。

## 实际修改

1. 移除设置行版本判断对全部业务初始化的拦截。布局继续按当前 APK 的完整扫描能力逐项安装，表盘保持自身精确版本守卫。
2. 新增 `HomeMoreDiscovery`，使用当前 base/split APK 的类、完整签名、原生点击调用关系和两个字段身份定位更多入口；要求唯一候选，不硬编码 `bk`、`am`、`t`。
3. 三个资源通过既有 `HostResources` 合并资源表及当前 R 字段校验。运行时核对 Fragment 的标题栏对象、标题栏的原生点击容器对象，以及唯一、可见的更多视图结构。
4. 更多入口不再依赖设置行版本守卫、设置行解析或布局开关。默认常驻，短按仍为宿主菜单，长按打开模块界面；原生已有长按时跳过。创建、原生点击重新绑定、晚安装回放及后续布局均沿用既有作用域与弱引用恢复机制。按钮尚未显示时仍保留页面观察器。
5. 入口和布局通过本次启动的 `HostDexSession` 共用 base/split 桥接对象。入口先查询，布局复用；双方完成后关闭。入口失败后布局仍可查询，布局命中缓存先结束时入口仍可查询，已经关闭的会话不得重开。未新增进程级页面强引用或修改布局缓存身份、预约重扫与规则版本；规则保持 8。
6. 设置行新增精确版本对 `17.0.8.320/1700008320`；表盘解析器新增该版本的 `f2/t0/l2` 方法表，默认关闭、能力和结果检查不变。
7. 补充真实 APK 的字段/资源契约、资源缺失、资源重复、重复类候选拒绝，以及桥接复用和失败释放检查；补充设置行和表盘的版本号错配拒绝检查。

设计沿用 KISS、DRY 和单一职责：独立解析器提供描述符，入口组只处理生命周期与长按，共用会话只管理 native 资源。未创建新分支、提交或修改忽略规则；保留任务开始时已有的设置页面及 Android 测试改动。

- `testDebugUnitTest lintDebug assembleDebug assembleRelease compileDebugAndroidTestKotlin` 成功。171 项 JVM 测试，0 失败、0 错误、0 跳过；已提供真实 APK、桌面 native、碰撞和结构 DEX 夹具。完整测试 XML 快照在 `build/adapt-8320-unit-results/`，构建日志为 `build/adapt-8320-build.log`。

- 最终代码对 17.0.7.320 与 17.0.8.300 分别运行 6 项真实 APK 测试，均无失败和跳过，生产查询各为 98/98 项、35 组。对应产物为 `build/adapt-scan-17.0.7.320.json`、`build/adapt-scan-17.0.8.300.json`，测试 XML 在各自的 `build/adapt-<版本>-apk-results/`。
