# 会员卡屏蔽包含活力人生会员

## 问题与定位依据

“我的”页原会员卡开关 `hide.mine.vip` 只折叠 `vip_layout`，新版会员权益区的标题和按钮仍然显示。

17.0.8.300 实际反编译产物中，`personal_center_head_info_card.xml` 的 `member_benefit_container` 包含 `member_benefit_header_layout` 和原 `vip_layout`。`CustomHeadView` 绑定该容器及 `header_left_text`，会员权益头部更新方法根据状态设置 `IDS_member_life` 并更新整个容器的可见性。由此确认新版会员区属于同一会员卡功能，不按动态显示文案匹配，不写死资源数字 ID 或混淆方法名。

定位产物：

- `build/host-17.0.8.300/resources/res/layout/personal_center_head_info_card.xml`
- `build/host-17.0.8.300/resources/res/layout/member_benefit_header_layout.xml`
- `build/host-17.0.8.300/sources/com/huawei/ui/main/stories/userprofile/scroll/CustomHeadView.java`

17.0.7.320 的当前原包未发现 `member_benefit_container`，保留原 `vip_layout` 路径。

## 实际修改

- 新会员权益容器并入原“会员卡”开关，配置键和默认关闭状态不变，无新增独立开关。
- 扫描同时解析新旧会员资源，任一容器有当前 APK 资源证据且页面生命周期通过校验即可支持该开关；两者都缺失时保持原界面，不影响账号等其他项。
- 复用现有页面观察器、安装组回调与弱引用回放，覆盖扫描晚于页面创建和会员区域异步布局更新；继续复用原折叠及恢复工具，不引入新框架或静态 View 强引用。
- 缓存复核保留原有全部资源校验，额外核对当前新版会员容器是否进入资源快照。旧缓存遗漏该容器时自动重扫；无新容器的旧版仍可复用合法缓存。APK 内容身份、split、预约重扫边界保持原有流程，规则版本仍为 8。
- 此开关折叠整个新版会员权益区域，包括标题、按钮和其下会员卡；不修改账号、会员状态或宿主业务请求。

实现遵循 KISS/DRY：复用原配置键、资源解析、页面回放及视图恢复逻辑，只增加已核验容器和必要缓存检查。
