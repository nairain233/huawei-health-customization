# 华为运动精简

基于华为运动健康`17.0.8.300`的用于精简华为运动健康界面，并提供可选的后台服务屏蔽与简易的自制本地表盘导入的模块。

“底栏精简”和“我的精简”分别提供“屏蔽红点和数字角标”开关，默认关闭，启用后需重启运动健康；仅隐藏提示，保留入口和未读数据。
