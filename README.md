# 华为运动精简

基于 libxposed API 102 的 LSPosed 模块，用于自定义华为运动健康的界面，以及按需屏蔽应用主动发起的服务调用。

## 支持范围

- 目标包：`com.huawei.health`
- 主适配版本：`17.0.7.320`（versionCode `1700007320`）；其他版本按 DexKit 定位结果逐项适配
- 页面：健康、运动、设备、我的，以及五项主界面底栏

非目标包、非主进程或非首包直接跳过。首次启动运动健康后后台扫描，匹配成功且已开启的项目独立安装；未命中、歧义或校验失败的项目保持原界面，不影响其他项目或独立的服务屏蔽。跨版本适配不等于所有版本全部兼容，未知的动态卡片、行项目和下发区块保持显示。

## 使用方式

1. 安装模块，在 LSPosed 中启用并将作用域设为华为运动健康。
2. 打开模块设置，启用“界面精简”。
3. 进入“布局精简”，再选择健康、运动、设备、我的或底栏分类，打开需要隐藏的项目。
4. 修改后彻底重启华为运动健康。扫描及缓存加载不阻塞启动，已错过的页面构造/绑定不会回放；相关页面需重新进入，必要时再次重启。

## 开关目录

后台服务管理入口独立于下面的布局开关，使用方式及限制见后文。

- 健康：搜索、更多菜单、快捷入口框、活动三环、编辑卡片、今日推荐、健康洞察、健康头条、提示卡。
- 运动：推荐、计划、户外跑步、瑜伽、健身五个子页的分类、搜索、菜单、Banner、快捷入口、计划、训练与课程区块。
- 设备：未登录旧页的提示、添加设备、列表、功能与推荐内容；已登录新版的设备／商城切换、主卡、设置条目、功能、表盘与商城。隐藏冲突时保留设备入口。
- 我的：消息、账号资料、会员卡、我的群组、家庭空间、年度目标、周月年报、勋章、我的页营销卡片（新品上市/新人福利），以及成就、数据、课程与计划、活动、路线、个人资料、订单、资产、iHealth Labs、设置、隐私、帮助、反馈、检查更新、关于。
- 底栏：健康、运动、会员、设备、我的。

## 后台服务精简

设置首页进入“后台服务精简”，按“低耦合服务”和“核心服务”选择业务组，再启用“启用服务屏蔽”。总开关与所有业务组默认关闭，与“界面精简”独立；开启核心服务组前会显示影响确认。修改保存成功后需彻底重启华为运动健康。

- 开启“调试模式”后可进入“自定义服务组件”，按服务类名或进程搜索、逐项屏蔽，也可使用“仅看已屏蔽”和“清空自定义规则”。目录读取已安装运动健康的服务声明，显示完整类名、进程、导出与启用状态；关闭调试模式会保留自定义规则并暂停生效。
- 业务分组说明用途和可能影响，不代表服务已确认可安全关闭。
- 仅拦截主进程通过标准 Context API 主动发起的显式服务启动与绑定，包括前台服务启动；按目标包及完整组件名精确匹配。
- 不立即停止运行中的服务，不保证阻止系统、其他应用、子进程、直接 Binder 调用或 PendingIntent 唤起；不管理广播、JobScheduler 或 WorkManager 调度。
- 屏蔽会使服务启动返回 `null`、绑定返回 `false`，可能影响依赖该服务的通知、设备连接和同步。应用若未处理失败返回也可能异常；取消屏蔽并重启可恢复模块放行。
- 服务不按运动健康版本号限制选择，由目标进程校验 ContextImpl 入口；更新后未发现的组件规则仍保留、允许取消，但不参与匹配。
- 配置读写使用 RemotePreferences；读取失败全部放行。保存期间保留已确认值，写入失败尝试恢复原始配置；无法确认恢复时暂停编辑，需重新连接配置服务并成功读取后恢复，普通刷新或重新打开页面不会解除暂停。页面配置不代表 Hook 已在设备上安装成功。
- 安装位置为 Application.attach 完成之后，早于此时的调用不在覆盖范围内。ContextImpl 签名不符合已核验规则时整项跳过，不扩大模块作用域。
