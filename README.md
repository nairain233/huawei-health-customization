# 华为运动精简

基于 libxposed API 102 的 LSPosed 模块，用于按一级模块粒度精简华为运动健康界面。

## 支持范围

- 目标包：`com.huawei.health`
- 唯一支持版本：`17.0.7.310`（versionCode `1700007310`）
- 页面：健康、运动、设备、我的，以及五项主界面底栏

版本号为空、版本不匹配、非主进程、非首包或符号不完整时，模块会直接跳过。未知的动态卡片、行项目和下发区块保持显示。

## 使用方式

1. 安装模块，在 LSPosed 中启用并将作用域设为华为运动健康。
2. 打开模块设置，启用“界面精简”。
3. 进入健康、运动、设备、我的或底栏分类，打开需要隐藏的项目。
4. **修改后需彻底重启华为运动健康两次。**

模块设置内提供 Miuix 风格的“关于”页，用于查看模块介绍、版本与开源引用；项目仓库地址暂以 TODO 占位。

所有 `hide.*` 开关默认关闭；开关开启表示隐藏。若五项底栏均被设置为隐藏，配置层和运行时都会自动恢复“健康”项。除这种保护场景外，“健康”底栏允许单独隐藏。
